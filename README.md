# THE MARK HOTEL - Luxury Hotel Booking Website

A complete, responsive hotel booking website that allows guests to explore hotel amenities, browse available rooms, make reservations, and manage their bookings through an intuitive interface.

## Live Demo
🔗 [https://themarkhotel.netlify.app/](https://themarkhotel.netlify.app/)

---

## Problem Solved

Many hotel websites suffer from:
- **Poor user experience** with cluttered, non-intuitive booking forms
- **Lack of real-time cost calculation** forcing users to manually compute totals
- **Inconsistent design** across different pages (home, rooms, booking, sign-in)
- **No visual feedback** during booking process causing user confusion
- **Non-responsive layouts** that break on mobile devices

**The Mark Hotel website solves these issues by providing:**
- A clean, modern booking form with real-time cost calculation (room + amenities)
- Fully responsive design that works seamlessly on desktop, tablet, and mobile
- Visual polish with warm, luxury color palette and proper spacing
- Interactive FAQ section with toggle answers
- Smooth navigation between all pages (Home, Rooms, Booking, Sign-in)

---

## Features

### Core Functionality
- ✅ **Real-time Booking Cost Calculation** – Room rates + amenities update instantly as user inputs data
- ✅ **Dynamic Room Selection** – Choose between Deluxe ($2500/night) and Suite ($4000/night)
- ✅ **Amenities Add-ons** – AC ($1000/night) and Locker ($300/night) with combined option
- ✅ **Advance Payment Validation** – Minimum $500 deposit required
- ✅ **Form Validation** – All required fields must be filled before submission
- ✅ **Checkbox Agreements** – Privacy Terms and Booking Conditions must be accepted

### Pages & Sections
| Page | Content |
|------|---------|
| **Home** | Hero section, About Us, Amenities gallery, FAQ accordion, Contact info |
| **Rooms** | Three room cards (Standard, Deluxe, Suite) with descriptions, prices, and Book Now buttons |
| **Booking Form** | Complete reservation form with customer info, room selection, payment details, special requests |
| **Sign-in** | Login/Sign-up toggle form with remember password option |

### UI/UX Improvements
- 🎨 **Warm luxury color palette** (cream, gold accents, navy) – no boring grey
- 📱 **Fully responsive** – works on all screen sizes
- ✨ **Smooth hover effects** on buttons, cards, and images
- 🧹 **Clean whitespace** for better readability
- 🔄 **Interactive FAQ** – click questions to reveal answers
- 💳 **Payment card icons** (Visa, MasterCard, Amex, Discover)
